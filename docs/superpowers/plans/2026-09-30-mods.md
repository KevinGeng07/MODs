# MODs Implementation Plan

> Executed inline in the session that wrote it (user asked to "build it out"). Spec:
> `docs/superpowers/specs/2026-09-30-mods-design.md`.

**Goal:** Go WAL/snapshot database + Python training session + local web UI, per spec.

**Architecture:** `modsdb` (Go, gRPC) owns all sample state; `mods` (Python) wraps the model,
DataLoader and training loop and relays DB change events to a vanilla-JS UI over WebSocket.

**Tech stack:** Go 1.27, grpc-go, protobuf; Python 3.13, torch 2.9.1, grpcio, FastAPI/uvicorn;
Cytoscape.js + dagre (jsDelivr).

## Global constraints

- CPU only; dataset fits in RAM; everything binds to 127.0.0.1.
- One WAL/wire encoding: protobuf messages from `modsdb.proto`.
- DataLoader workers use `multiprocessing_context="spawn"`, one gRPC channel per process.
- Codegen: `grpcio-tools` (bundled protoc) in `.venv` (system site packages), Go plugins via `go install`.

## Tasks

- [x] **1. Toolchain + proto.** `.venv`, `db/proto/modsdb/v1/modsdb.proto`, `scripts/gen_proto.sh`
      → `db/gen/modsdbv1/*.pb.go`, `python/mods/db/_pb/*`.
- [x] **2. WAL** (`db/internal/wal`): framed records, CRC32C, segment rotation, reader that stops
      at torn tail. Tests: round trip, truncate-at-every-offset, corrupt byte, rotation.
- [x] **3. Snapshot + manifest** (`db/internal/snapshot`, `db/internal/manifest`): atomic write,
      CRC footer, manifest log replay. Tests: round trip, corrupt snapshot rejected, manifest replay.
- [x] **4. Engine** (`db/internal/engine`): memtable with immutable rows and status index, op
      validation, group-commit loop, recovery, auto snapshots + WAL truncation, checkpoints, restore.
      Tests: property test vs reference map with crash/reopen, snapshot equivalence,
      checkpoint/restore, concurrent increments under `-race`, expect_version conflicts.
- [x] **5. Hub** (`db/internal/hub`): ring buffer, bounded subscribers, LAGGED/RESET. Tests: backlog
      replay without gaps/dupes, slow subscriber dropped, commits never block.
- [x] **6. gRPC server + binary** (`db/internal/server`, `db/cmd/modsdb`): handlers, error mapping,
      stats. Test: in-process bufconn server smoke test.
- [x] **7. Python client + FakeStore** (`python/mods/db`): tensor conversion, same interface both.
      Tests against FakeStore and real binary.
- [x] **8. Data + session + graph** (`python/mods/data.py`, `session.py`, `graph.py`): EpochSampler,
      DBDataset.__getitems__ with FetchAndMark, TrainingSession commands, fx graph JSON.
      Tests: sampler determinism/skip, evaluate leaves mode + RNG untouched, queue count while
      paused, save→train→restore→train gives identical batch ids and losses.
- [x] **9. FastAPI + WebSocket + UI** (`python/mods/server`): routes from spec §6.6, 50 ms event
      coalescing, panels from spec §7.
- [x] **10. Example + launcher** (`examples/digits_mlp.py`, `README.md`): seed digits, start modsdb,
      start server, open browser. Verify end to end in the browser.
